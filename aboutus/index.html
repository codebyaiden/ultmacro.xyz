THE PROJECT

Built in the open.
Run one at a time.

Ultimate Macro is a free, open-source automation tool for Roblox Tower Defense Simulator, maintained by developers and QA contributors from the community.

THE IDEA

Make the good run
worth keeping.

Record a strategy while you play. Save it, replay it, tune it and share it as a .strat file.

Ultimate Macro was originally created by Darksen on March 30, 2026. After he stepped away from active development, a new team continued the project with updates, fixes and new features.
