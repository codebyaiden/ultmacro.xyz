What’s new in v1.4.1.4?

  • Renamed Scroll amount to Map-list scroll steps. It controls scrolling in the map and mode menu, not how many matches run.
  • There is no fixed 20-match cap. Use F2 or the dashboard stop control whenever you want to stop.
  • Kept the 1.4.1.3 gameplay engine, recorder, dashboard, restart flow, and automatic chat closing.
  • Added regression checks for runs beyond 20 match-end and relaunch decisions.
