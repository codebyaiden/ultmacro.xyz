New

  • Adaptive resolution support across 16:9 resolutions from 720p all the way to 4K, with 8K scaling included.
  • Completely upgraded Discord personal-bot interface with Components V2 cards, buttons, menus, screenshots, status controls, and strategy selection.
  • Added optional Discord gateway support for faster bot commands and status updates.
  • Added Strategy Lab, spatial-action systems, new strategy metadata, and expanded QA resources.
  • Added the new Ultimate Macro icon and refreshed interface assets.

Improved

  • Faster actions, faster inputs, cached delays, and improved overall macro performance.
  • Improved image detection with resolution-aware search scaling.
  • Improved tower placement, upgrades, recovery, watchdog behavior, and action confirmation.
  • Improved Roblox window handling, camera alignment, coordinate scaling, and multi-resolution support.
  • Improved Discord setup, bot health checks, token validation, command feedback, and strategy controls.
  • Rebuilt the release on the stable 1.3.5 foundation while bringing over the best RC features.
  • Improved UI layout, bot setup, token fields, connection status, and command feedback.

Fixed

  • Fixed actions breaking when using resolutions other than 1920×1080.
  • Fixed image searches using incorrect bounds on different resolutions.
  • Fixed legacy submacros failing to adapt to different screen sizes.
  • Fixed Discord replies failing when no active interaction was available.
  • Fixed missing runtime files and Strategy Lab components from the unstable RC build.
  • Fixed multiple recovery and confirmation issues that could cause actions to stop early or behave inconsistently.
