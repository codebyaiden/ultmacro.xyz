What changed

New

  • Profile Manager - import and export settings, hotkeys, and strategies, with previews and backups.
  • Official Discord Remote Control - use EngineerBot to start, stop, check status, and take screenshots.
  • Auto Configure Settings - optionally prepare Roblox settings before launch and restore them after closing.
  • Arcade Recording - added Arcade mode, an editable map field, and Arcade/Trial selection.
  • Added log controls, custom bot prefixes, and commands for version, stats, logs, and strategy selection.

Improved

  • Improved image detection, matchmaking, camera alignment, Auto Equip, and Party invites.
  • Improved watchdog recovery and reduced CPU usage.
  • Safer updates with backups, rollback, and strategy protection.
  • Improved webhook handling and Discord settings pages.

Fixed

  • Fixed detection issues with moved windows and multiple monitors.
  • Fixed recording, replay scaling, cloning, and Brawler repositioning.
  • Fixed upgrade issues, tower tracking, and attempts to upgrade maxed towers.
  • Fixed hotbar selection, DJ tracks, and Support Caravan blocking Drop the Beat.
  • Fixed Party Mode, difficulty selection, and Ready button issues.
  • Fixed stuck inputs after stopping, watchdog cleanup, and personal-bot commands.
  • Fixed Auto Spin paths and missing-window handling.
  • Fixed Official Remote connection-code decoding and screenshot encoding crashes.

Removed

  • Removed three outdated Frost strategies. Frost mode is still supported.
  • Disabled automatic strategy refresh in Git checkouts only.
