What changed

Ultimate Macro 1.4.0.37

Fixes since the public 1.4 build

  • Correct Easy/Casual selection and recognize the current Survival menu, including Fallen and Frost cards below the first row and narrow/docked layouts.
  • Improve auto-equip search focus and input timing; clear the first and fifth slots using the live inventory row; recognize the exact DJ Booth caption for DJ strategies. Every equipment action still requires an owned control and a confirmed result.
  • Fix the strategy-rotation crash that tried to read a nonexistent third slot.
  • Make Advanced settings and Match options open into view. Stop native fields from jumping the page or remaining over offscreen content.
  • Save valid recording shortcuts when leaving their fields. Conflicting/reserved shortcuts keep the previous working bindings and show an explanation.
  • Import supported preferences from older 1.3.6 .ump profiles without importing private fields or replacing strategies.
  • Refresh docked window rendering and wait for a stable replacement game window during relaunch.
  • Fix the graphics cleanup error when closing the macro.
  • Keep signed ZIP downloads separate from installation: background checks/downloads are optional, installation still needs approval, and the old folder stays in place.

Notes

  • Close Roblox chat manually if it covers the game. The retired fixed-position chat click is disabled because the Roblox topbar changed.
  • Windows may show its capture indicator during target-window OCR. Do not disable Windows security settings to hide it.
  • Older strategies may need updates after TDS map, tower or balance changes. This update is not a guarantee that every community strategy wins or that no bugs remain.

Updating

Use Settings → Check for updates, then Review update → Install. Extraction creates a separate version folder. Open that folder's Main.ahk when ready; nothing installs or restarts the macro without your approval.
