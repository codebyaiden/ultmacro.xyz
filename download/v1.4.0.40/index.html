What changed

This is the exact Windows AutoHotkey ZIP already available from the official download page and verified by the stable in-app updater. If you already have 1.4.0.40, you don't need to reinstall.

Changes since the previous GitHub release (1.4.0.38)

  • Reduced UI lag when scrolling, switching tabs, and resizing.
  • Added Settings → Private server to save a TDS invite and use it when joining or reconnecting.
  • Prevented setup timeouts and false disconnect detections from repeatedly closing or relaunching Roblox.
  • Improved recognition for Survival mode, Restart, Play Again, and 2× Timescale. Tower placement now waits for the previous tower menu to close.
  • Added key delay, extra game-UI recognition time, and a pre-join delay under Advanced settings. Strategy details now show modifiers.

Download the Windows ZIP, extract it, and open Main.ahk. In-app updates still require your approval before installation.
