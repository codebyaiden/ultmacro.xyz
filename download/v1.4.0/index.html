What changed

New and improved

  • New interface: Searchable strategy library, required tower list, scrollable settings, and an Output panel you can export for bug reports.
  • Appearance: Christmas theme, optional background, adjustable opacity, startup sounds, and community translations.
  • Roblox docking: Put the macro beside the game, then undock to restore the layout.
  • Recording: Record as you play, capture upgrade and sell clicks, and place towers without typing an ID for each one. Stop, F2, and F8 keep an editable draft.
  • Signed ZIP updates: With the optional updater helper, new versions can download quietly. You still review and approve installation. Updates install into a separate folder and never restart the macro automatically.
