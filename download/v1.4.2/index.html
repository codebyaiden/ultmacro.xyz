What changed

What's New

  • Cleaned up the UI with better spacing, clearer labels, and a new, larger app icon.
  • Added Farming Goals. Set a Coins or Gems target and track your progress in the Run tab.
  • Added two-strategy rotation. Switch after a set number of runs or minutes and automatically equip the right loadout.
  • If a tower placement fails and a retry works, the macro can save the corrected spot to your strategy and keep a backup.
  • Added Start with Windows and a setting for what happens when you close the window. The macro stays in the system tray by default.
  • Discord win and loss results now show a compact summary with rewards, Spin Tickets, Timescale Tickets, and a separate match screenshot.
  • Added daily runtime logs in AppData to help troubleshoot failed runs.

Fixes & Removals

  • After clicking Play Again, the macro repeats map selection and starts the next match in the same Roblox session.
  • If Roblox says “You need $…”, the macro waits 10 seconds and retries the same tower spot. If the spot is blocked, it tries progressively farther spots.
  • If the tower panel doesn’t open after placement, the macro clicks away and checks the spot again before attempting another placement.
  • Reduced repetitive tower placement retry messages in Discord.
  • Removed the hotkey upgrade, Restart, and Play Again toggles. All three are enabled by default.
  • Removed the Output, Ready, and Idle footer text and the Changes scroll buttons. The version is at the bottom of Settings.
  • Added a notice when the macro moves to the system tray.
  • Removed unused code, organized internal files, and consolidated user instructions into one README.

The Dashboard, including the Strategy Library and Earnings, is unavailable until the next version.
