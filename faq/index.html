BEFORE YOU START

A few things
worth knowing.

The quick answers for setup, strategies and the end of a match.

What can Ultimate Macro automate?

It records and replays tower placements, upgrades, selling, repositioning, target changes, abilities and other match actions. It can also rotate strategies, equip required towers, replay finished matches and collect playtime rewards.

Where should I start?

If you are using Ultimate Macro for the first time, download the latest ZIP from the official releases, extract it, install AutoHotkey v2.0, and check the setup requirements before running Main.ahk.

How do I make a strategy?

You play a run, record the actions you want to keep, then save them as a .strat file. You can open the file later, inspect the actions and replay it.

Can I use community strategies?

Yes. You can download community-made .strat files and load them in the macro. The project also includes example strategies in the repository.

What happens when a match ends?

It can handle match endings with Restart and Play Again flows, then continue with the next part of the run when the setup allows it.

Can I run a strategy faster?

Yes. Ultimate Macro supports 1.5× and 2× timescale modes.

Does it support VIP servers and parties?

Yes. It supports VIP servers and party matches.

What do I need before installing?

Use Windows 10 or 11, install AutoHotkey v2.0 and the English (US) OCR language pack, set Windows scaling to 100% and configure the TDS settings listed in the ready check.

Which download should I use?

For a ready-to-use install, download the latest ZIP from the official releases. The main branch is the production/runtime tree; the dev branch is for development.

What can Discord reporting send?

Depending on what you configure, it can send session statistics, debug logs, result screenshots and progress updates to your Discord server.

Can I control it from my phone?

Phone control is one of the features being built. It is not part of the ready-to-use download yet.
