Here's what Ultimate Macro does

Record a strategy.

Capture placements, upgrades, sells, targeting and abilities. Save the run as a .strat file.

Play it back.

Choose a saved strategy. Ultimate Macro follows its recorded actions through the match.

Automate the routine.

Auto Equip towers, skip waves, use supported abilities, and rotate two strategies by runs or minutes.

Run together.

Set up a Party, use a VIP server, or connect optional Discord notifications and remote controls.

More features

Strategy library

Search built-in and local strategies, then import a .strat file.

Match setup

Choose a map, mode, modifiers and required tower loadout.

Game detection

OCR and image matching read game state and help verify actions.

Timescale and rewards

Use 1.5× or 2× timescale tickets and collect playtime rewards.

Discord

Send run notifications. With consent, link remote controls and share session stats.

Controls and updates

Set hotkeys, arrange the app beside Roblox, choose a language and check for verified updates.

Party and VIP servers

Set host and member roles, party usernames and when to leave if someone is missing.

Match recovery

Handle match results, reconnect after disconnects and continue the session.
