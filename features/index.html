WHAT IT DOES

Stop doing
the same run.

Set up a strategy once, then let Ultimate Macro handle the repeatable parts of a TDS run.

01 · RECORD

Save the run
you already know.

Capture placements, upgrades, abilities, selling, repositioning, target changes and other match actions in one reusable strategy file.

02 · REPEAT

Keep the match
moving.

Equip towers, check the map, handle match endings and use Restart or Play Again when the flow calls for it.

03 · REPORT

Keep an eye
on the run.

Send session statistics, debug information, result screenshots and progress updates to Discord.
