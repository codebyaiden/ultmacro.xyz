Set up each match

Keep the strategy, game and tower loadout aligned before replay starts.

Choose a strategy

Search files in the app’s Strategies folder, pick a bundled example, or use + to browse to a downloaded .strat file.

Set the match

Choose the map, mode and modifiers. The strategy shows its required towers and saved hotbar order; optional map checking verifies the selection. Map-list scroll steps can be adjusted for long menus.

Equip and align

Auto Equip selects the required towers. The macro also aligns the camera before replaying the strategy.

Choose the automation

Enable Auto Skip Waves, Ability Spam, Call of Arms, Support Caravan or Drop the Beat. Raise the Dead, Hologram and Reposition use your configured game hotkeys.

Set a play speed

Choose 1.5× or 2× Timescale when you have a ticket. Pizza Party, Badlands II and Polluted Wasteland II do not support it.

Check what the game shows

Image matching and OCR help detect game menus, result screens, reward text and tower states so the macro can verify steps instead of relying only on timing.

Handle the long parts

Set the stopping point, choose when to switch plans, and let the macro deal with repeat-match steps.

Rotate between two strategies

Switch after a chosen number of runs or minutes. The change happens between matches, and the matching loadout is equipped.

Stop at a Coins or Gems goal

Set a target. The macro counts match-result rewards and stops after the current match when the total reaches or passes it. Gems require Hardcore or an eligible event mode.

Collect playtime rewards

When a reward check is due, it opens the claim panel, verifies the claim and reads the claimed count. Six claims schedule the next check in 24 hours; fewer or unreadable claims are checked again after 2 hours.

Continue after a result or disconnect

Play Again and Restart are enabled by default. After a win or loss, the macro repeats map selection in the same Roblox session when the next screen is confirmed. It also retries a recognized disconnect; if a result screen cannot be confirmed, it reopens Roblox to recover.

Recover a blocked tower spot

It rechecks the placement and searches up to 50 wider positions. If the tower panel fails to open, it checks the spot again before another placement. Confirmed corrections are saved to the active strategy with a backup; if placement cannot be confirmed, it stops safely.

Wait for enough in-game cash

If Roblox says there is not enough cash, the macro waits 10 seconds and retries the same tower spot.

These features help repeat runs, but they cannot guarantee a nonstop 24/7 session. Keep the PC awake, check your connection, and supervise a full match before leaving it running.

Record your own strategy

Play a match with Roblox in the foreground and save the actions as a reusable .strat file.

Captured actions

Tower placement, top or bottom upgrades, sells, target changes, camera alignment, DJ track changes, Hologram and supported abilities.

  • Set map, mode, modifiers and required towers before recording.
  • Optionally record movement and raw keyboard or mouse input while Roblox is in the foreground.
  • Rebind the recording shortcuts in the Record tab.
  • Save the result as a .strat file and choose it from Run.

See what each match returned

Choose what the macro sends to Discord. Webhooks and ULT Bot control are separate, optional links.

  • Win and loss cards with rewards, XP, Coins, Gems, and detected Spin or Timescale Tickets.
  • Optional run screenshots and a separate webhook for result screenshots.
  • Optional session stats, debug logs, and pings for wins, losses or Timescale events.
  • ULT Bot can check status and stop; run starts and screenshots each need your permission.

Controls, tools and updates

Set the app up around the way you run Roblox.

  • Rebind game and recording hotkeys, set input delays, use number-key hotbar controls, and close Roblox chat before macro actions.
  • Start with Windows, keep the app in the system tray when closed, keep it on top, and choose its background and animation settings.
  • Save a VIP server link; use the separate spin-wheel or consumable-crate tools with F3/F4.
  • Download verified updates in the background, review them, and approve installation into a new folder.
  • Daily runtime logs in AppData help track down failed runs.

Dashboard status The website Dashboard, including Strategy Library and Earnings, is unavailable in v1.4.2. CPU temperature needs LibreHardwareMonitor’s local web server.
