Setup guide/Discord

Discord

Optional Discord result webhooks and ULT Bot controls.

The Discord tab can send match results and optional run details to your own server. To get a webhook URL: create a Discord server, open any channel's settings → Integrations → Create Webhook → Copy Webhook URL. Paste it in, tick Enable Webhook, then use Test Webhook to confirm it works before saving.

  • Result summaries — wins or losses, rewards, XP, and Spin or Timescale Tickets when detected.
  • Debug logs — optional run messages for troubleshooting.
  • Run screenshots — optional screenshots while a match is running.
  • Result screenshots — the end-of-match screen, with an option to send it to a second webhook.
  • Pings — optionally mention a Discord user for wins, losses or Timescale events.
Treat your webhook URL like a password — anyone who has it can post to that channel. Use a private channel, and remember screenshots may include your username and other on-screen information.

Remote control

Link the official ULT Bot with /remote link. It can check status and stop runs. You can separately allow run starts and screenshots; screenshot requests can be limited to when Roblox is in front. Disconnect the link in Settings at any time.

Strategy Library and Earnings on the website Dashboard are unavailable in v1.4.2.
