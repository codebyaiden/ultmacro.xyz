Setup guide/Display settings

Display settings

Keep Windows, Roblox and the game layout consistent so the macro can read the screen.

These are the settings the macro asks you for on first launch. Three different things are involved and they are easy to confuse: your Windows display resolution, your Windows display scale, and the settings inside Roblox and TDS.

Windows

SettingValueWhy
Windows display resolutionSupported 16:9The current image and coordinate systems adapt across supported 16:9 resolutions. 1920×1080 is still the recommended reference setup.
Windows display scale100% 100% is the recommended baseline for predictable OCR and UI geometry. Test other Windows scaling levels before unattended use.
Windows taskbarVisible The macro will not work with the taskbar hidden.
OCR language packEnglish (US) Required for reading wave numbers, currency and result screens.

Roblox

SettingValueWhy
Maximum Frame Rate60 FPS Keeps animation and UI timing predictable so the macro's waits line up with reality.
Camera ModeClassic Camera alignment during placement assumes the classic camera.
Graphics ModeManual Automatic graphics change the picture mid-session, which changes what image detection sees.
UI Navigation ToggleEnabled Required by the macro's menu handling.

Tower Defense Simulator

SettingValueWhy
TDS UI ScaleLarge The macro's reference images of buttons and menus are captured at this scale.
TDS Screen ShakeDisabled Shake moves the interface mid-frame and causes missed clicks and false detections.
TDS Vertical UpgradesEnabled "Prefer Vertical Upgrades" fixes the upgrade panel layout so the path buttons are always where the macro expects.
TDS DialogDisabled Dialog boxes cover parts of the screen the macro reads.
Show Tower OptionsEnabled The macro needs the tower option panel visible to upgrade, sell and change targeting.
Do not use custom Roblox fonts — altered letterforms break the OCR that reads wave numbers and currency. Newer builds can apply the Roblox side of this list for you with Auto Configure Settings, restoring your originals afterwards.
