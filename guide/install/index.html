Setup guide/Install

Install

Extract the release and start Ultimate Macro with bundled AutoHotkey v2.0.31.

  1. Download the release

    Get the latest ZIP from the download page. Every build is also on the official GitHub releases page — download from nowhere else.

    Download page

  2. Extract the whole archive

    Extract every file into its own folder; do not run the macro from inside the ZIP. Keep Main.ahk, Internal, lib, Resources and Strategies together.

  3. Use the bundled AutoHotkey

    Start Ultimate Macro.cmd starts the bundled 64-bit AutoHotkey v2.0.31. You do not need a separate AHK install for the launcher. If you run Main.ahk directly, use AutoHotkey v2.0.31 or newer.

  4. Start Ultimate Macro

    The app opens to Run. Its tabs are Run, Record, Discord, Settings, Tools, Tutorial and Changes. Follow Tutorial → Setup before the first match. Use Record to make a .strat file.
