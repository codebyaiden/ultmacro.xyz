Setup guide/Longer sessions

Longer sessions

Learn about strategy rotation, goals, recovery and repeat runs.

Strategy Rotation

The Run tab can hold two strategies. Turn on Strategy Rotation and set Swap after a number of Runs or Minutes to alternate between them — useful for splitting a session between a coin farm and a gem farm, or across two different maps.

Farming goals

Set a Coins or Gems target on Run. The macro counts match-result rewards and stops after the current match when the total reaches or passes the target. Gems require Hardcore or an eligible event mode.

Timescale

If you have Timescale Tickets, set Timescale to 1.5x or 2x on Run. A ticket is required. Timescale is not available on Pizza Party, Badlands II or Polluted Wasteland II.

Private servers

Paste a private server link into VIP Server Link in Settings and turn on Use VIP server.

Between matches

After a win or loss the macro uses Play Again or Restart, then repeats map selection. Check the map verifies the selected map. Collect playtime rewards claims playtime rewards when due and checks the claimed count before scheduling another check.

Recovery

When the macro detects a Roblox disconnect, it closes Roblox and tries to reconnect. If it cannot confirm the expected screen after a result, it reopens Roblox and tries to recover. Keep the PC awake and the network connected; recovery cannot prevent every interruption.

When something is slow

If actions are missed, adjust Upgrade Delay, Mouse Delay or Key Delay in Settings, then supervise another full match before leaving it unattended.
