GETTING STARTED

Set it up once.
Then press play.

The macro reads the Roblox screen, so a consistent setup helps it follow the strategy as expected.

01

Download it

Get the latest release ZIP and extract every file into its own folder.

02

Install AutoHotkey

Install AutoHotkey v2.0. The older 1.1 release is not supported.

03

Set up TDS

Match the Roblox and Windows settings in the ready check below.

04

Run Main.ahk

Choose a community strategy or record your own, then start when Roblox is ready.

READY CHECK

Make Roblox look
how the macro expects.
