A FEW QUESTIONS

Before you
start a run.

The short version of what it does, what it needs and where to look next.

Come say hi in Discord ↗
What does it actually do?

It records and replays the parts of a TDS run you would rather not do twice: placements, upgrades, selling, repositioning, target changes and abilities. It can also rotate strategies, equip towers and handle the end of a match.

How do I make a strategy?

Open Create → Record a Strategy, play the run, then save it as a .strat file. Use Strategy Lab when you need to refine it.

What happens when a match ends?

When a match ends, it can use Restart or Play Again when appropriate, verify the selected map and continue with the next run.

What should I set up first?

Use Windows 10 or 11, install AutoHotkey v2.0 and the English (US) OCR language pack, use a supported 16:9 display, keep 100% Windows scaling as the baseline and match the TDS settings in the ready check.

Can I use a community strategy?

Yes. Open the Main tab's Community view, or load a community-made .strat file with Browse.

Which download is for me?

For a ready-to-use install, download the latest ZIP from the official releases. You do not need source-code branches to get started.
