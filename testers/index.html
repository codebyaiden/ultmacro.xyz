Automated Logs: please read

This build offers Automated Logs. If you opt in inside Ultimate Macro, diagnostic reports are sent automatically to the development team's private Discord channel after runs, recoveries, or manual stops.

Reports can contain system information, macro settings, strategy names and actions, timings, errors, match outcomes, and verified rewards. Full planned strategy steps need separate permission inside the app.

No passwords, arbitrary typed keys, chat messages, personal files or screenshots are intended to be collected. This particular test build sends reports directly to a Discord webhook. Participation is optional in the app, and you can disable it later. Don't redistribute the ZIP.
