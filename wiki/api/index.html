How to use it

  1. 01Copy the link above.
  2. 02Give it to a bot or AI tool that can read JSON from a URL.
  3. 03Use the guides as sources. Each article includes a link back to the Wiki.

Only published documentation is included. Draft and unverified topics aren't part of this data.

For developers: example code and API status

Fetch the dataset, then search the articles array. Each article contains a title, summary, keywords, sections, and source URL.

const res = await fetch('https://ultmacro.xyz/wiki/api/v1/articles.json');
const { articles } = await res.json();
const matches = articles.filter(article =>
  article.title.toLowerCase().includes('ocr'));

The separate search endpoints under /api/wiki/v1/ are not live yet. The complete JSON link above works now; the dynamic endpoints require the website's production proxy to forward them to the Node service.
