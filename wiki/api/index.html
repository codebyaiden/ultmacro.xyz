Wiki API

Read published Ultimate Macro guides from a bot, website, or AI application. Public JSON. No account or API key required.

Use citations from the returned url field. Results are documentation, not live diagnosis. Research-only topics are excluded.

Endpoints

GET /api/wiki/v1Discovery GET /api/wiki/v1/articlesList guides GET /api/wiki/v1/articles/:slugFull article GET /api/wiki/v1/search?q=...Search GET /api/wiki/v1/categoriesCategories GET /api/wiki/v1/openapi.jsonOpenAPI 3.1 GET /wiki/api/v1/articles.jsonStatic full snapshot

Quick start

const response = await fetch('https://ultmacro.xyz/api/wiki/v1/search?q=ocr'); const { data } = await response.json(); for (const guide of data) console.log(guide.title, guide.url);

Using the docs with AI

Fetch the search endpoint, retrieve the full article for the best-matching slug, and provide the article URL as a citation. If the article doesn't cover the user's question, say you could not verify an answer. Never silently invent a fix from an empty result.

Deployment note: The live proxy must forward /api/wiki/v1/* to the Node website service for the query endpoints. The static JSON snapshot works as a public fallback on ordinary static hosting.

Access and limits

Read-only GET and HEAD requests; OPTIONS support for browser clients. No authentication or user-specific data. Search text is limited to 160 characters and result counts are capped. Responses support ETags and short caching. Be considerate with polling and cache article data locally.
