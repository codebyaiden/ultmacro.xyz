    03

    Know what comes back

    The response is intentionally small. Answers cite published guides; unsupported questions stay unanswered.

    Answered 
    {
  "status": "answered",
  "answer": "Documented steps…",
  "answer_type": "extractive",
  "citations": [{
    "title": "Relevant Wiki guide",
    "url": "https://ultmacro.xyz/wiki/?article=…",
    "version": "v1.3.x"
  }]
}

    Illustrative shape, not an actual API response. Show the source URL with the answer.

    No documented answer 
    {
  "status": "not_found",
  "answer": null,
  "citations": [],
  "message": "…"
}

    HTTP 200 can still mean no answer. Never use related guides as proof of a solution.

    Optional version filters the documentation release. The default sourced mode is extractive, not AI-generated. HTTP errors (400/413/415/5xx) are separate from not_found.
