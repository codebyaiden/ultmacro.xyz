Developer example and live search API status

Use the compact index without processing the full published-guide JSON dataset.

const { articles } = await (await fetch(
  'https://ultmacro.xyz/wiki/api/v1/index.json'
)).json();
const guide = articles.find(a =>
  a.keywords.includes('ocr') || a.title.toLowerCase().includes('ocr'));
const markdown = guide && await (await fetch(guide.markdown)).text();
// Include guide.url and guide.version with answers.

When production routing forwards /api/wiki/v1/ to the Node service, bots can also call /api/wiki/v1/search?q=upgrade, request paginated search results, or use /api/wiki/v1/context?q=upgrade for short sourced excerpts. These endpoints need a working production proxy; the static index and Markdown files don't.
