# Abilities don't activate

> Fix mismatched TDS ability keybinds.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=abilities-not-working
Source: /guide/troubleshooting/

## Check both sets of keybinds

1. Open TDS and find the key assigned to the ability.
2. Open Ultimate Macro → Settings → TDS Keybinds.
3. Set the matching key in both places.
4. Test the ability manually, then in a short supervised macro run.

## Why there may be no error

The macro sends the configured key press. If the game expects a different key, no action happens, even though the macro sent its input.
