# AutoHotkey v1 vs v2

> Make sure Main.ahk uses the 64-bit v2 interpreter.

Status: published
Version: v1.3.x
Category: Start here
Article: https://ultmacro.xyz/wiki/?article=ahk-versions
Source: /guide/install/

## Supported interpreter

| Setting | Value |
| --- | --- |
| Required | AutoHotkey v2.0 |
| Architecture | 64-bit |
| Not compatible | AutoHotkey v1.1 |

## Check the association

Both AutoHotkey versions can coexist on Windows.

1. Install 64-bit AutoHotkey v2.
2. Check the default application for .ahk files.
3. Open Main.ahk again with the v2 launcher.
4. If a 32-bit warning appears, change to the 64-bit build.
