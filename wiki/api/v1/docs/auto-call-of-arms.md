# Auto Call of Arms

> Run supported abilities at configured intervals.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=auto-call-of-arms
Source: /guide/tools/

## Set up intervals

1. Open Tools → Auto Call of Arms.
2. Choose the Call of Arms and Drop the Beat ability options.
3. Set each desired interval in seconds.
4. Make sure the Settings keybinds match TDS.
5. Press F3 to start and F4 to stop.

## Important

Either ability can be disabled independently. The tool cannot activate an unavailable in-game ability.
