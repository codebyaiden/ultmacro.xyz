# Auto Open Consumable

> Use the standalone crate-opening utility.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=auto-consumable
Source: /guide/tools/

## Opening consumables

1. Open Tools → Auto Open Consumable.
2. Confirm the intended consumables are available.
3. Press F3 to start opening crates.
4. Watch the count and stop with F4.

## Counter

The tool reports how many crates it opened.
