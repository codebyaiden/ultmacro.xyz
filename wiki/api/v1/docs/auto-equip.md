# Auto Equip Towers

> Let a strategy's required towers be equipped before the match.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=auto-equip
Source: /guide/first-run/

## Enable it

The Main tab offers Auto Equip Towers for strategies with a defined loadout.

1. Choose a strategy with tower requirements.
2. Confirm the Roblox account owns every required tower, including golden variants.
3. Enable Auto Equip Towers.
4. Observe the loadout before your first match.

## Limits

Auto Equip cannot equip a tower the account doesn't own. It is unavailable in Legacy Mode.
