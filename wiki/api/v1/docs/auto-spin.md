# Auto Spin

> Automate the spinning wheel with the separate Auto Spin tool.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=auto-spin
Source: /guide/tools/

## Using Auto Spin

1. Open Tools → Auto Spin.
2. Check the spin interface is available in TDS.
3. Press F3 to start the tool.
4. Monitor the ticket count while it runs.
5. Press F4 to stop.

## Counter

The documented tool counts how many tickets were used.
