# Restart, Play Again and map checks

> Set the behavior the macro uses between matches.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=between-matches-settings
Source: /guide/sessions/

## Options

| Setting | Value |
| --- | --- |
| Click Restart | Used after a loss; normally enabled |
| Click Play Again | Used after a win; normally enabled |
| Check the map | Verifies the destination map and can reload if incorrect |
| Collect playtime rewards | Claims available daily and playtime rewards |

## Recommended test

Run one match and observe the result-screen action and map selection. For a win-only strategy entering the wrong map, try turning Restart off.
