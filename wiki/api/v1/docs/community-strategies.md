## Use a shared strategy

1. Open Strategy Network and find a strategy for your mode or map.
2. Check the tower loadout and other listed requirements.
3. Download or choose the strategy through the supported workflow.
4. Run a supervised match before leaving it unattended.

## After a game update

An older strategy may no longer match current game behavior, even if its file loads. Check its requirements and look for a newer version if it fails.
