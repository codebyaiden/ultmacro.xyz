# Set a currency goal

> Let the macro select compatible strategies until a target is met.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=currency-goals
Source: /guide/sessions/

## Goal behavior

The documented Goals feature uses a currency target, not only a fixed number of runs, and selects compatible strategies toward it.

## Set up

1. Open the session goal controls in your installed version.
2. Choose the currency and target.
3. Check that compatible strategies are available.
4. Watch the first run and confirm progress updates.
5. Verify that the session stops at the intended target.
