# Capture debug logs for support

> Record the event around a failure without sharing private data.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=debug-logs-export
Source: /guide/troubleshooting/

## Reproduce and collect

1. Open Settings and enable Debug Logs.
2. Run until the failure happens once.
3. Note the last successful action and the action that should have followed.
4. Collect the relevant local log excerpt, with personal information removed.
5. Include macro version, Windows resolution and screen scaling in the support report.

## What makes a report useful

A short reproducible log is more useful than an entire unrelated session history.
