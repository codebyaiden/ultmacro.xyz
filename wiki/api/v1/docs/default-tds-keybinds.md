# Default TDS ability keybinds

> Match the recorded macro keys to Tower Defense Simulator.

Status: published
Version: v1.3.x
Category: Setup & settings
Article: https://ultmacro.xyz/wiki/?article=default-tds-keybinds
Source: /guide/first-run/

## Default bindings

| Setting | Value |
| --- | --- |
| Call of Arms | C |
| Drop the Beat | B |
| Support Caravan | J |
| Raise the Dead | V |
| Hologram | K |
| Reposition | L |
| Upgrade | E |
| Bottom path | Z |
| Cancel placement | Q |

## Verify both sides

In Ultimate Macro open Settings → TDS Keybinds, then compare each assigned key with TDS itself. A mismatch can make an ability do nothing without an error.
