## Available images

Automatic screenshots can be sent periodically; Triumph and Loss screenshots capture the end-of-match result screen. The result images can use a second webhook.

## Privacy check

1. Choose a private channel.
2. Enable the screenshot types you want.
3. Check a test result for user names or other personal details.
4. Share only redacted examples with public support.
