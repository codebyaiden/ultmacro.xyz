# Discord session statistics

> Understand OCR-based session information sent to Discord.

Status: published
Version: v1.3.x
Category: Community
Article: https://ultmacro.xyz/wiki/?article=discord-statistics
Source: /guide/discord/

## Enable the report

1. Create a private Discord webhook.
2. Enable the webhook from the macro's Discord tab.
3. Select Send Statistics.
4. Use Test Webhook, then check a live match update.

## What numbers mean

Statistics are read with OCR. If a value is wrong, fix Windows OCR and Roblox fonts before treating it as a Discord problem.
