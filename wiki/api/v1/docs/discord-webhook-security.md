# Keep Discord webhook URLs private

> A leaked webhook can be used to post into your channel.

Status: published
Version: v1.3.x
Category: Community
Article: https://ultmacro.xyz/wiki/?article=discord-webhook-security
Source: /guide/discord/

## Before sharing configuration

1. Do not paste a webhook URL into a public issue or Discord message.
2. Redact the URL from screenshots and logs.
3. Use a private channel for the macro's screenshots and session events.
4. If leaked, delete or regenerate the webhook in Discord and update the macro settings.
