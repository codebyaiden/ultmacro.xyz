# Schedule DJ discs by wave

> Use wave-based DJ track changes instead of manual timing where supported.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=dj-wave-schedule
Source: /guide/recording/

## Available recording behavior

The documented recorder supports DJ disc changes with Ctrl + D and a wave-based schedule.

## Validate the sequence

1. Set the intended DJ change in the strategy's recording flow.
2. Confirm the starting DJ track.
3. Run a supervised replay and note the wave on which the disc actually changes.
4. Adjust the strategy if the match reaches the change earlier than expected.
