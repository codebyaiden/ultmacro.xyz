# Edit a strategy

> Open a .strat file in Strategy Lab.

Status: published
Version: v1.3.x

Article: https://ultmacro.xyz/wiki/?article=edit-strategy
Source: /guide/recording/

## Open Strategy Lab

1. In Ultimate Macro, open Create.
2. Choose Edit a Strategy or Open Strategy Lab.
3. Open the .strat file you want to inspect or change.
4. Save a separate copy before replacing a strategy that already works.

## Standalone editor

You can also launch StrategyLab.exe from the release folder. Strategy Lab is the visual editor for strategy actions. Test an edited strategy before relying on it.
