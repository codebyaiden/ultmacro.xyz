## Default

In the released Settings hotkey map, EnforcerVan defaults to N. This is separate from the other tower ability keys.

| Setting | Value |
| --- | --- |
| SWAT Van | N |

## Recording

The Main.ahk tooltip says to hold Ctrl with the configured SWAT Van ability key during recording.

1. Check the game’s current ability keybind.
2. Set the same key in Settings → TDS Keybinds.
3. During recording press Ctrl with that key to capture the ability.
4. Replay a short match to verify the action occurred.
