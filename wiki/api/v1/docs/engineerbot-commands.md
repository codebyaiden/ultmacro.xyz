# EngineerBot remote commands

> Supported remote start, stop, screenshot and status controls.

Status: published
Version: v1.3.x
Category: Community
Article: https://ultmacro.xyz/wiki/?article=engineerbot-commands
Source: /guide/discord/

## Supported actions

| Setting | Value |
| --- | --- |
| Start / stop | Control the macro remotely |
| Status | Query current macro state |
| Screenshot | Inspect what the Windows PC shows |
| Version / stats / logs | Fetch relevant diagnostics |
| Selected strategy | Query the active strategy |

## Before trusting remote stop

Test local F2 control first and verify the bot's connection. Discord connectivity cannot repair a broken local macro session.
