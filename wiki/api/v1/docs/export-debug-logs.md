# Export logs from the Settings page

> Use the built-in Export Logs button for reproducible error reports.

Status: published
Version: v1.3.5
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=export-debug-logs
Source: https://github.com/UltimateMacro/Ultimate-Macro-New-Era/blob/v1.3.5/Main.ahk

## Where it is

In v1.3.5 the Settings panel includes an Export Logs button wired to ExportLogsForDevelopers.

1. Enable Debug Logs when investigating a problem.
2. Reproduce the failure in one short session.
3. Open Settings and select Export Logs.
4. Inspect the exported material and remove account names, paths or tokens before sharing it.

## What to include

Report the macro version, game mode, resolution, scaling, expected action and observed result. The log should support the report, not replace the reproduction steps.
