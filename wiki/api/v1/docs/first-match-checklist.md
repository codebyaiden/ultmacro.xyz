# First-match checklist

> Use one match to confirm the whole playback loop.

Status: published
Version: v1.3.x
Category: Start here
Article: https://ultmacro.xyz/wiki/?article=first-match-checklist
Source: /guide/first-run/

## Before pressing F1

- Supported 16:9 resolution and visible Windows taskbar
- TDS UI Scale: Large, Screen Shake: Disabled
- Roblox at 60 FPS with Classic camera
- Correct tower loadout and TDS keybinds

## During the run

1. Watch the first placement and confirm the tower appears.
2. Confirm at least one upgrade follows the intended path.
3. Watch for end-of-match detection and correct return to the next game.
4. Stop with F2 if anything mismatches and note which step failed.
