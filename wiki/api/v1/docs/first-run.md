# Run your first strategy

> Test a built-in strategy before leaving the macro unattended.

Status: published
Version: v1.3.x
Category: Start here
Article: https://ultmacro.xyz/wiki/?article=first-run
Source: /guide/first-run/

## Start a test run

1. Open Roblox and join Tower Defense Simulator.
2. Open Ultimate Macro. On the Main tab, select a strategy that came with the release.
3. Confirm you have the towers required by that strategy.
4. Make sure Windows, Roblox, and TDS settings match the setup pages.
5. Select Start or press F1.
6. Watch a full match, including upgrades and the end-of-match screen.

## Stop safely

Press F2 to stop the macro and release held input. Check placement, upgrades, result detection, and the next-match transition before running longer sessions.
