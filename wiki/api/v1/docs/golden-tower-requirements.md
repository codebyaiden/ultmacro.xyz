# Specify golden tower requirements

> How the recording loadout denotes golden variants.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=golden-tower-requirements
Source: /guide/recording/

## Tower list format

Recording accepts a comma-separated tower list. Use the G prefix for a golden version, such as G Minigunner, alongside regular names like Ranger or Commander.

## Check before sharing

1. Confirm the golden tower variant is required by the strategy.
2. Include it in the recording metadata.
3. Tell users they must own it before trying Auto Equip.
4. Test that the matching loadout is equipped.
