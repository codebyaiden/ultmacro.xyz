# Hotkeys & keybinds

> Playback and recording shortcuts in the documented release.

Status: published
Version: v1.3.x
Category: Setup & settings
Article: https://ultmacro.xyz/wiki/?article=hotkeys
Source: /guide/recording/

## Playback

| Setting | Value |
| --- | --- |
| Start macro | F1 |
| Stop macro | F2 |

## Recording

| Setting | Value |
| --- | --- |
| Place tower | F |
| Upgrade | Ctrl + U |
| Sell tower | Ctrl + X |
| Change target | Ctrl + ` |
| Change DJ track | Ctrl + D |
| Align camera | Ctrl + T |
| Hologram tower | Ctrl + Alt + H |
| Delete last recorded action | Ctrl + B |
| Record inputs | Ctrl + Shift + E |

## Change shortcuts

Recording shortcuts are configurable under Settings → Recording Hotkeys. For abilities, confirm the keybinds in Settings → TDS Keybinds also match TDS.
