# Install Ultimate Macro

> From ZIP download to first launch.

Status: published
Version: v1.3.x
Category: Start here
Article: https://ultmacro.xyz/wiki/?article=install
Source: /guide/install/

## Download and extract

1. Download the ZIP from the official Ultimate Macro download page.
2. Right-click the ZIP and extract the whole archive to a folder. Do not run Main.ahk inside the ZIP.
3. Install 64-bit AutoHotkey v2 from autohotkey.com/v2. AutoHotkey v1.1 will not work.
4. Open Main.ahk in the extracted folder.

## Before your first run

- Windows resolution: supported 16:9; scaling: 100% recommended
- Windows taskbar: visible
- Roblox: 60 FPS, Classic camera, Manual graphics
- TDS: Large UI, Screen Shake off, Vertical Upgrades on
