# Main.ahk won't open

> Fix common startup failures.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=launch-fails
Source: /guide/troubleshooting/

## Check in this order

1. Extract the entire ZIP before running anything.
2. Install 64-bit AutoHotkey v2.0. v1.1 cannot run Main.ahk.
3. Make sure .ahk files open using the AutoHotkey v2 launcher.
4. Close Roblox Account Manager and other multi-instance utilities.
5. Open Main.ahk again.

## If the error remains

Share the exact error, AutoHotkey version and Ultimate Macro version when requesting support.
