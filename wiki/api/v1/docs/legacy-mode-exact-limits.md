# Legacy Mode: exact limits

> What Legacy Mode changes and which features it disables.

Status: published
Version: v1.3.5
Category: Setup & settings
Article: https://ultmacro.xyz/wiki/?article=legacy-mode-exact-limits
Source: https://github.com/UltimateMacro/Ultimate-Macro-New-Era/blob/v1.3.5/Main.ahk

## Released behavior

The v1.3.5 tooltip says Legacy Mode changes image detection and applies only to 1920×1080. Auto Equip and tower targeting are unavailable while it is enabled.

| Setting | Value |
| --- | --- |
| Required resolution | 1920×1080 |
| Auto Equip | Unavailable |
| Tower targeting | Unavailable |
| Changing setting | Restarts macro |

## When troubleshooting

1. Confirm whether Legacy Mode is enabled.
2. Use the adaptive mode first if you need Auto Equip or tower targeting.
3. If testing Legacy Mode, set Windows to 1920×1080 and verify the run.
4. Return to adaptive mode if required features disappear.
