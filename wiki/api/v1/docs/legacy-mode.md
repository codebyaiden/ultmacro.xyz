# Auto Equip or targeting stopped working

> Legacy Mode deliberately disables some features.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=legacy-mode
Source: /guide/troubleshooting/

## Check Legacy Mode

Legacy Mode disables Auto Equip and target changes. Turn it off to use those features.

## What to do

1. Open Settings and check whether Legacy Mode is enabled.
2. Disable it to use the adaptive image-detection path.
3. Retest Auto Equip and tower targeting.
4. Only use Legacy Mode as a fallback when necessary; it can retain 1920×1080 limitations.
