# Legacy Mode and resolution limits

> Why Legacy Mode is a fallback for display detection.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=legacy-resolution
Source: /guide/troubleshooting/

## Known limitation

The public setup guide warns that Legacy Mode can retain 1920×1080 limitations and disables Auto Equip and target changes. Use adaptive detection when possible.

## Test

1. Check whether Legacy Mode is enabled.
2. Disable it if Auto Equip or target changes are needed.
3. Use a supported 16:9 resolution; test at 1920×1080 if troubleshooting.
4. Retest with a bundled strategy before returning to long runs.
