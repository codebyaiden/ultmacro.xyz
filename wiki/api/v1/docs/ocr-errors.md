# Wave or cash detection is wrong

> Correct missing OCR language support and font changes.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=ocr-errors
Source: /guide/troubleshooting/

## Fix OCR

1. Install the English (United States) Windows OCR language pack.
2. Remove custom Roblox font modifications.
3. Use 100% Windows scaling as a test baseline.
4. Keep wave and currency UI visible and unobstructed.
5. Run a short test and compare the on-screen value to the value in macro logs.

## Still incorrect?

Save the release version, screen resolution and a cropped screenshot showing the wrong value. Remove private details before sharing it.
