# Install missing OCR language

> Correct text detection when English (US) OCR support is absent.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=ocr-language-fix
Source: /guide/troubleshooting/

## Windows requirement

Ultimate Macro uses Windows OCR for currency, wave numbers and result screens.

1. Install the English (United States) Windows OCR language pack.
2. Reopen Ultimate Macro after installation.
3. Remove any custom Roblox fonts.
4. Compare a live wave/currency value against the macro's detection.

## When reporting

Include a cropped screenshot of the value being read incorrectly, the resolution, scaling and release version.
