# Join as a party member

> Configure the Member role to wait for a host invitation.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=party-member
Source: /guide/sessions/

## Member setup

1. Open the Party tab and choose Member.
2. Enter the host's display name.
3. Choose the expected leave/rejoin behavior.
4. Save, then wait for the host invitation.
5. Verify all accounts entered the same match.
