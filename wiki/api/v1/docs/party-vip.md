# Party & VIP servers

> Private server links and Host/Member party configuration.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=party-vip
Source: /guide/sessions/

## VIP server

1. Paste a private server link into VIP Server Link.
2. Enable Use VIP Server.
3. Confirm that the Roblox account can join that server manually before testing the macro.

## Party mode

1. Open the Party tab.
2. Select Host to create a party and invite others, or Member to wait for an invite.
3. Enter the host's display name and members' names.
4. Choose whether to return to the lobby when all or any party member leaves.
5. Save and test the group with all accounts present.
