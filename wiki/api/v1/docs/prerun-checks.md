> Review resolution, scaling, OCR and dependencies before playing.

Status: published

Source: /guide/sessions/

## What is checked

The documented pre-run diagnostics include Windows resolution, display scaling, OCR and missing dependencies.

## If a check fails

1. Identify the failing prerequisite.
2. Open the matching Windows or macro setting.
3. Correct it without changing unrelated settings.
4. Rerun the check before starting a long session.
