# Export a working profile

> Back up settings, hotkeys and strategies in one bundle.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=profile-export
Source: /guide/discord/

## Before changing versions

1. Open Profile Manager.
2. Export the working settings, hotkeys and strategies.
3. Save the file somewhere outside the release folder.
4. Check the backup exists before editing or importing another setup.

## Check what was actually protected

A profile export alone is not proof that every file in the installation folder is backed up. User recordings and bundled strategies have separate locations in v1.3.5.

1. Keep the exported profile outside the release folder you may replace.
2. Copy saved recordings from %APPDATA%\Ultimate_Macro\Recordings if that folder exists.
3. Back up any edited strategy files from Resources\Strats in the release folder.
4. Check that the exported profile and separate copies exist before changing versions or importing.
