# Import a profile safely

> Restore a bundle without losing your current setup.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=profile-import
Source: /guide/discord/

## Protect the existing profile

1. Export your current working profile first.
2. Open Profile Manager and select Import.
3. Review its preview of settings, hotkeys and strategies.
4. Confirm the intended replacements and keep a backup.
5. Test one strategy after importing.
