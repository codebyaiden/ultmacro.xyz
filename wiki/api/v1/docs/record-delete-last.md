# Undo the last recorded action

> Remove a mistaken recorder action with Ctrl + B.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=record-delete-last
Source: /guide/recording/

## During recording

1. Pause before recording the next action.
2. Press Ctrl + B to remove the last recorded action.
3. Check the remaining sequence before continuing.
4. Save a separate test .strat and replay it to verify the correction.

## Default hotkey

Ctrl + B is the documented default Delete Record shortcut; it can be changed in Recording Hotkeys.
