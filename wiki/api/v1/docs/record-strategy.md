# Record a strategy

> Turn a played match into a .strat file.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=record-strategy
Source: /guide/recording/

## Before recording

Pick your map, mode and tower loadout. Confirm the game and recording keybinds first. The recorder captures actions as you play, not a guaranteed successful strategy.

## Record and save

1. Open Create → Record a Strategy.
2. Play a match normally. Use the recording shortcuts for placement, upgrades, selling and other actions.
3. If an action was recorded incorrectly, use Delete Record (Ctrl + B) before continuing.
4. Finish recording and save the result as a .strat file.
5. Replay the new strategy under supervision before sharing it.

## Useful shortcuts

| Setting | Value |
| --- | --- |
| Place | F |
| Upgrade | Ctrl + U |
| Sell | Ctrl + X |
| Change target | Ctrl + ` |
| Change DJ track | Ctrl + D |

## Recording tip

Leave enough time for game animations and currency changes. Fast manual actions may need longer delays to replay reliably on other PCs.
