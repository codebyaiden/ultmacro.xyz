# Recording ability options

> Understand the recording controls for abilities and wave skipping.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=recording-ability-toggles
Source: /guide/recording/

## Available recording options

| Setting | Value |
| --- | --- |
| Use Call of Arms | Record or enable relevant ability automation |
| Use Support Caravan | Include support ability use |
| Use Drop the Beat | Include DJ ability use |
| Auto Skip Waves | Include recorded skip behavior |
| Abilities Spam | Set the recorder's repeated ability option |

## Before replay

Confirm game keybinds and ability ownership on the receiving account. A toggle is not proof a tower or ability is available.
