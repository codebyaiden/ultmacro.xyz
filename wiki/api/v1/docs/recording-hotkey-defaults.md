## Default recorder shortcuts

A caret (^) in the AutoHotkey source denotes Ctrl; plus denotes Shift, and exclamation denotes Alt.

| Setting | Value |
| --- | --- |
| Place Tower | F |
| Upgrade Tower | Ctrl + U |
| Align Camera | Ctrl + T |
| Change DJ Track | Ctrl + D |
| Sell Tower | Ctrl + X |
| Delete last recording | Ctrl + B |
| Record inputs | Ctrl + Shift + E |
| Hologram | Ctrl + Alt + H |

## If a shortcut does nothing

1. Open Settings → Recording Hotkeys.
2. Compare your current keys with the list above; a customized profile can change them.
3. Make sure Roblox has keyboard focus and the recorder is active.
4. Test one action and verify it was captured before completing a full strategy.
