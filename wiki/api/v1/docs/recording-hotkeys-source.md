## Defaults in Main.ahk

These keys are read from the RecordingHotkeys section and can be changed by the user. They are not always the current bindings on an existing installation.

| Setting | Value |
| --- | --- |
| Place tower | F |
| Upgrade tower | Ctrl+U |
| Align camera | Ctrl+T |
| Delete last recorded action | Ctrl+B |
| Record inputs | Ctrl+Shift+E |

## When a shortcut fails

1. Open the recording keybind settings.
2. Compare the configured combination with the macro defaults.
3. Check for conflicts with Roblox or another desktop application.
4. Re-test a single recorded action in a supervised session.
