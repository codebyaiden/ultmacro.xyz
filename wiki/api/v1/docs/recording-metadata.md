# Strategy recording setup

> Set map, mode, towers and modifiers before capturing actions.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=recording-metadata
Source: /guide/recording/

## Create → Record a Strategy

1. Choose the map and mode from the dropdowns.
2. Enter required towers as a comma-separated list.
3. For a golden tower, prefix the name with G, for example G Minigunner.
4. Hold Ctrl while selecting multiple modifiers.
5. Choose ability toggles, wave skipping and optional starting movement as needed.
6. Record your match and save its .strat file.

## Supported mode families

The documented recorder includes Easy, Casual, Intermediate, Molten, Fallen, Frost, Hardcore, Voidcore and Arcade, plus map-specific selections. The game may change available modes.
