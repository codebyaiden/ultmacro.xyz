# Record multiple modifiers

> Use Ctrl selection when preparing a strategy recording.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=recording-modifiers
Source: /guide/recording/

## Choose modifiers

1. Open Create → Record a Strategy.
2. Find the Modifiers control.
3. Hold Ctrl while selecting or deselecting additional modifiers.
4. Confirm your selection before starting the match.
5. Save and replay the strategy to verify the configuration.

## Why record metadata

A strategy without correct mode and modifier information can run on the wrong configuration even when its actions are valid.
