# Record opening movement

> Configure optional starting movement before tower placement.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=recording-movement
Source: /guide/recording/

## Move option

The documented recording form can move your Roblox character in a chosen direction for a specified number of milliseconds at the start of a run.

## Use carefully

1. Open the recording setup.
2. Choose a starting direction only when the strategy requires it.
3. Set a short movement duration in milliseconds.
4. Record and test the opening sequence before extending the duration.
