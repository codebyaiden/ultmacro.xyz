# Record a repeatable strategy

> Avoid capturing rushed actions that fail on replay.

Status: published
Version: v1.3.x

Source: /guide/recording/

## Before recording

The recorder saves what you actually do. A winning match doesn't guarantee a repeatable strategy if clicks and upgrades are too tightly spaced.

## Improve your recording

1. Use stable Windows and TDS settings.
2. Allow UI panels to open before taking the next action.
3. Wait for cash to become available before upgrading.
4. Use descriptive filenames, for example pw2_solo_farm.strat.
5. Replay the finished file and watch the whole match.
