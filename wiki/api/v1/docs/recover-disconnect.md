# Roblox disconnects during a run

> What recovery handles and what to check when it stalls.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=recover-disconnect
Source: /guide/sessions/

## Automatic recovery

Ultimate Macro can reconnect Roblox and re-enter TDS after a disconnect. If it stops at a login prompt or unexpected dialog, use the checks below.

## If it doesn't rejoin

1. Check whether Roblox can connect normally.
2. Dismiss unexpected Roblox dialogs or login prompts.
3. Stop with F2 if possible and save the recent logs.
4. Retry while watching the reconnect sequence and identify the screen where it gets stuck.
