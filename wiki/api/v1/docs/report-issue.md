# Report an issue

> Give developers a reproducible report instead of a vague description.

Status: published
Version: v1.3.x
Category: Community
Article: https://ultmacro.xyz/wiki/?article=report-issue
Source: https://github.com/UltimateMacro/Ultimate-Macro-New-Era/issues

## Collect the important details

1. Enable Debug Logs in Settings.
2. Reproduce the problem once, if safe.
3. Note the version, Windows resolution and game settings.
4. Describe the expected result and actual result.
5. Attach the relevant log and a redacted screenshot when useful.
6. Search existing GitHub issues before filing a new one.

## Where to send it

Send the report to GitHub Issues or the official Discord support channel. Remove credentials and webhook URLs from any logs.
