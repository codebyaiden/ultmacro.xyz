# When to use Restart versus Play Again

> The exact end-of-match distinction used by the released macro.

Status: published
Version: v1.3.5
Category: Sessions & tools

Source: https://github.com/UltimateMacro/Ultimate-Macro-New-Era/blob/v1.3.5/Main.ahk

## Different result screens

The Settings tooltips state that Click Restart acts after a loss, while Click Play Again acts after a win.

| Setting | Value |
| --- | --- |
| Restart | After a loss |
| Play Again | After a win |

## Wrong map after a win

The source specifically recommends turning Restart off if a winning strategy sometimes ends on the wrong map.

1. Check what result the game displayed.
2. Confirm whether the macro clicked Restart or Play Again.
3. For a win-only strategy with the wrong destination, test disabling Restart.
4. Watch the next match's map selection before leaving the PC.
