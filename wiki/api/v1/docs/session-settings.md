# Long session settings

> Goals, timescale, and between-match actions.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=session-settings
Source: /guide/sessions/

## Goals and Timescale

| Setting | Value |
| --- | --- |
| Goals | Set a currency target; the macro selects compatible strategies until the goal is reached. |
| Timescale | In Settings, use 1.5× or 2× with available timescale tickets. |

## Between matches

| Setting | Value |
| --- | --- |
| Click Restart button | Used after a loss; enabled by default. |
| Click Play Again button | Used after a win; enabled by default. |
| Check the map | Verifies the destination map after joining and reloads if wrong. Recommended on. |
| Collect playtime rewards | Claims playtime and daily rewards when available. |

## Before a long session

Watch one full match first. If you are running a win-only strategy and Restart lands you on the wrong map, try disabling the restart action.
