# Macro is slow or misses inputs

> Adjust timing and performance settings without breaking placement.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=slow-inputs
Source: /guide/troubleshooting/

## Change one delay at a time

1. Open Ultimate Macro Settings.
2. If upgrades are skipped while the upgrade panel loads, raise Upgrade Delay.
3. If mouse actions happen too quickly, increase Mouse Delay.
4. If key presses are missed, increase Key Delay.
5. Test a short run after each adjustment so you know which change helped.

## On weaker PCs

Potato Mode lowers macro overhead on slower machines. Try it before switching image detection methods.

- Keep Legacy Mode off unless needed as a fallback.
- Legacy Mode may be limited to 1920×1080 and disables Auto Equip and target changes.
