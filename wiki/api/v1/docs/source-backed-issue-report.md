# Make a reproducible issue report from code evidence

> Collect useful version, screen state and logs for a real bug.

Status: published
Version: v1.3.5 source inspection
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=source-backed-issue-report
Source: https://github.com/UltimateMacro/Ultimate-Macro-New-Era/blob/v1.3.5/README.md

## Useful evidence

1. Record the installed Ultimate Macro version and which release tag it came from.
2. Write the exact action expected and action observed.
3. Note Windows resolution/scaling, Roblox FPS, TDS UI Scale and map/mode.
4. Capture a cropped screenshot of the unexpected state.
5. Include a redacted log excerpt, not account tokens or private webhook URLs.

## Avoid speculative diagnosis

A missed click can be caused by map geometry, cash, a changing UI, or input timing. The report should separate observed facts from proposed causes.
