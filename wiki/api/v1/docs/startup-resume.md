# Start from lobby or Ready screen

> How resume-aware startup handles a running Roblox session.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=startup-resume
Source: /guide/sessions/

## Supported states

Documented releases can start while Roblox is already in the TDS lobby or on the Ready screen.

## Before testing

1. Check the correct Roblox window is focused.
2. Open the macro with a known-good strategy.
3. Observe the existing game state being recognized.
4. Stop with F2 if it attempts a wrong transition.
