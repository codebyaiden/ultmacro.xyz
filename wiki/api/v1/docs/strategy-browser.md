# Community and My Strats

> Use the Main tab's built-in strategy browser.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=strategy-browser
Source: /guide/first-run/

## Choose a source

On Main → Strategies, Community contains shared strategy cards and My Strats contains your own files.

1. Open the Strategies browser.
2. Use Community to inspect a shared strategy, or My Strats for your recordings.
3. Use Browse to select a local .strat file when needed.
4. Review required towers, map and mode before pressing Start.

## Don't skip the test

Community cards and download metadata do not guarantee a strategy will work after a TDS update. Watch its first match.
