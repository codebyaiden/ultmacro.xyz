## Documented fields

Strategy Lab's code reference includes an [Info] section used by published strategy files. Gameplay-income estimates are descriptive, not verified guarantees.

| Setting | Value |
| --- | --- |
| title | Public strategy name |
| author | Creator attribution |
| desc | Useful restrictions and setup notes |
| income | Claimed farming yield |
| time | Approximate run length |

## Improve a shared strategy

1. Name the map and mode in a useful title or description.
2. Identify tower requirements and optional modifiers.
3. Record a tested run and note the conditions.
4. Avoid claiming exact hourly earnings without consistent measurements.
