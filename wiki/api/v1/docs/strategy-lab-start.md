# Open Strategy Lab

> Launch the visual .strat editor from the Create tab or release folder.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=strategy-lab-start
Source: /guide/recording/

## Two entry points

1. Open Ultimate Macro and select Create → Open Strategy Lab or Edit a Strategy.
2. Alternatively, run StrategyLab.exe from the fully extracted release folder.
3. Open a copy of the .strat you want to inspect.

## Backup

Strategy Lab is a visual editor. Save a backup before changing the original strategy file.
