## In the v1.3.5 source

The packaged Strategy Lab is described as a separate visual editor with placement footprints, tower attack ranges, map backgrounds, calibration persistence and split-path range tracking.

| Setting | Value |
| --- | --- |
| Open from | Create → Strategy Lab, or StrategyLab.exe |
| Input | .strat file |
| Visual context | Placement positions, footprints, ranges and map background |

## Safe edit workflow

1. Back up the original .strat.
2. Open the copy in Strategy Lab.
3. Change one spatial action or related sequence.
4. Save the edited file under a new name.
5. Reopen the file, then test the strategy in a supervised match.
