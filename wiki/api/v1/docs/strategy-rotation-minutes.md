# Rotate strategies after minutes

> Use a time interval rather than a run count.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=strategy-rotation-minutes
Source: /guide/sessions/

## Main tab

1. Choose two strategies.
2. Turn on Strategy Rotation.
3. Choose Minutes under Swap after.
4. Set the intended interval.
5. Watch the first switch and verify the target strategy.

## Avoid surprises

The time setting controls rotation; it does not make an incompatible strategy work with the current towers.
