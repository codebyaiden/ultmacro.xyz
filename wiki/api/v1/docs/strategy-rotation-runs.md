# Rotate strategies after runs

> Switch between two strategies after a chosen run count.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=strategy-rotation-runs
Source: /guide/sessions/

## Main tab

1. Select two strategies on Main.
2. Enable Strategy Rotation.
3. Choose Runs for Swap after.
4. Enter how many runs to complete before switching.
5. Watch at least one switch to confirm both strategies start correctly.

## Pre-check

Both strategies need compatible maps, modes and tower loadouts.
