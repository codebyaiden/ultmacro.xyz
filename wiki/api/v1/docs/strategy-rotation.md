# Rotate strategies

> Alternate between two strategies after a run count or time limit.

Status: published
Version: v1.3.x
Category: Strategies
Article: https://ultmacro.xyz/wiki/?article=strategy-rotation
Source: /guide/sessions/

## Configure rotation

1. On the Main tab, choose the two strategies you want to alternate.
2. Enable Strategy Rotation.
3. Set Swap after to a number of Runs or Minutes.
4. Test each strategy on its own before starting rotation.

## Check compatibility

The selected strategies may require different maps or towers. Make sure both can run with your current loadout and settings.
