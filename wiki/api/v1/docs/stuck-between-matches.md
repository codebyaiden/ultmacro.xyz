# Stuck after a match

> Check restart, play-again, and map verification.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=stuck-between-matches
Source: /guide/sessions/

## Check the transition

1. Check whether the macro stopped on a win, loss, lobby, or Ready screen.
2. Verify that Click Restart and Click Play Again are configured for your strategy.
3. Keep Check the map enabled so a wrong map can be detected.
4. Stop with F2 and replay a single strategy while watching the transition.
5. Save the last log entry and the screen state if it gets stuck again.

## Wrong map after a win-only run?

Disable Click Restart if a win-only strategy sends you to the wrong map.
