## Configure TDS in-game

Open Tower Defense Simulator's settings before running the macro. These are in-game settings, not Windows display options.

| Setting | Value |
| --- | --- |
| UI Scale | Large |
| Screen Shake | Disabled |
| Prefer Vertical Upgrades | Enabled |
| Dialog | Disabled |
| Show Tower Options | Enabled |

## Confirm the settings

1. Set UI Scale to Large and disable Screen Shake.
2. Enable Prefer Vertical Upgrades and Show Tower Options; set Dialog to Disabled.
3. Return to a supervised test match and confirm that the tower upgrade panel and placement controls remain usable.
