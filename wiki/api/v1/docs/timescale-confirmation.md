# Check Timescale ticket prompts

> Diagnose a Timescale prompt before a faster run.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=timescale-confirmation
Source: /guide/sessions/

## First checks

1. Confirm the account has the required Timescale tickets.
2. Select 1.5× or 2× in Settings.
3. Run once under supervision and watch the confirmation flow.
4. If a ticket prompt prevents starting, return to normal speed and collect the exact prompt.

## Scope

The documented public release supports Timescale. Confirm button labels and confirmation behavior against the installed build before escalating a bug.
