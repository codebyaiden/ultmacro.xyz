# Use Timescale tickets

> Configure 1.5× or 2× matches when you have tickets.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=timescale-tickets
Source: /guide/sessions/

## Configure Timescale

1. Confirm that timescale tickets are available on the Roblox account.
2. Open Ultimate Macro Settings.
3. Set Timescale to 1.5× or 2×.
4. Run one match while watching its timing and game transitions.

## Check the strategy

Faster games reduce run time, but a strategy still needs to work at the selected speed. Return to standard speed if the run repeatedly stalls or misses actions.
