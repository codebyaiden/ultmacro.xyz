## Automatic fallback

The v1.3.5 Main.ahk tooltip states that if Timescale tickets run out, the run continues at normal speed.

| Setting | Value |
| --- | --- |
| 1.5× | More stable, suits most strategies |
| 2× | Requires a strategy built for 2× timing |
| No tickets left | Continues at normal speed |

## If the match appears slow

1. Check whether tickets are still available in TDS.
2. Check the TimeScale setting in Ultimate Macro.
3. Compare the strategy's intended speed against the actual speed.
4. Test under supervision before assuming a macro freeze.
