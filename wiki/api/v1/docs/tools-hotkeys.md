# Tools shortcuts: F3 and F4

> Start and stop the separate tools from their own windows.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=tools-hotkeys
Source: /guide/tools/

## Tool controls

The Tools tab opens utilities in always-on-top windows. F3 starts the selected tool and F4 stops it.

1. Choose Auto Call of Arms, Auto Spin or Auto Open Consumable.
2. Open the tool's window.
3. Press F3 to begin its task.
4. Press F4 to stop it.
