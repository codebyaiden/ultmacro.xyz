# Built-in tools

> Auto Call of Arms, Auto Spin, and Auto Open Consumable.

Status: published
Version: v1.3.x
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=tools
Source: /guide/tools/

## Open a tool

The Tools tab opens utilities in separate always-on-top windows. F3 starts the selected tool; F4 stops it.

## Available tools

| Setting | Value |
| --- | --- |
| Auto Call of Arms | Triggers Call of Arms and Drop the Beat on configured intervals; each ability can be disabled. |
| Auto Spin | Claims spinning-wheel prizes and counts tickets used. |
| Auto Open Consumable | Opens consumable crates and counts how many were opened. |
