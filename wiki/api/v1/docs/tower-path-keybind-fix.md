# Bottom-path upgrade key mismatch

> Check the macro's upgrade and bottom path bindings.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=tower-path-keybind-fix
Source: /guide/troubleshooting/

## Check the keys

The setup guide lists E for Upgrade and Z for Bottom path as defaults.

1. Open TDS and check its current upgrade and path shortcuts.
2. Open Ultimate Macro Settings → TDS Keybinds.
3. Make the matching keys identical.
4. Enable TDS Prefer Vertical Upgrades.
5. Replay one upgrade and verify the intended path.
