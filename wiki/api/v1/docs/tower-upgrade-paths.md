## Record upgrades

The recorded strategy format supports top and bottom upgrade paths as separate actions.

1. Confirm TDS Prefer Vertical Upgrades is enabled.
2. Record the tower placement first.
3. Use the correct upgrade hotkey for the intended path.
4. Save the .strat and replay until you confirm the right path was upgraded.

## Troubleshoot

If paths differ during replay, verify TDS keybinds and panel layout. Increase Upgrade Delay only when the panel is late opening.
