# Use Hotkeys for Upgrading

> Understand the switch that changes how the macro upgrades towers.

Status: published
Version: v1.3.5
Category: Setup & settings
Article: https://ultmacro.xyz/wiki/?article=upgrade-hotkeys-setting

## What it does

When enabled, the macro presses TDS’s upgrade key instead of clicking the upgrade panel. The released tooltip explicitly recommends enabling it.

## Check the setup

1. In Settings, enable Use Hotkeys for Upgrading.
2. Confirm your TDS Upgrade key matches Ultimate Macro's TDS Keybinds.
3. Make sure Prefer Vertical Upgrades is enabled in TDS.
4. Test one top-path and one bottom-path upgrade.

## Don't confuse delay and keybind problems

An upgrade that selects the wrong path requires checking vertical upgrades and keys first; a panel that opens late is a timing issue.
