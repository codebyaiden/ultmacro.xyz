# Upgrades fail or use the wrong path

> Check the upgrade panel, money, keybinds and delay.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=upgrade-not-working
Source: /guide/troubleshooting/

## Troubleshoot upgrades

1. Confirm the tower has enough cash for the action.
2. Enable Prefer Vertical Upgrades in TDS.
3. Check that the upgrade and bottom-path keybinds in Ultimate Macro match your game settings.
4. Increase Upgrade Delay in Settings if the panel opens slowly.
5. Replay the same step while supervising and record which upgrade was missed.

## What changes the diagnosis

If the macro clicked the wrong button, check UI settings. If it clicked before the panel appeared, increase the delay. These are different problems.

## Distinguish why an upgrade was skipped

Insufficient cash, a delayed tower panel, a misplaced click, and the wrong upgrade path require different checks. Identify the symptom before changing settings.

1. Note the tower, wave, intended path, and whether enough cash was visible.
2. If the wrong path upgraded, check Prefer Vertical Upgrades and your upgrade and bottom-path keybinds.
3. If the panel appeared late, increase Upgrade Delay conservatively and retry the same step.
4. If the panel never opened or the click landed elsewhere, check display settings and Roblox focus instead.
5. If it persists, share redacted debug logs with the version and expected versus actual action.
