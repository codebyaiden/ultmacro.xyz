# What Reset to Default actually changes

> The reset action affects settings and hotkeys, not your strategies or Discord setup.

Status: published
Version: v1.3.5
Category: Setup & settings
Article: https://ultmacro.xyz/wiki/?article=what-reset-settings-changes
Source: https://github.com/UltimateMacro/Ultimate-Macro-New-Era/blob/v1.3.5/Main.ahk

## Included in reset

The confirmation dialog in Main.ahk explicitly says it resets TDS keybinds, recording hotkeys, macro settings and advanced settings.

| Setting | Value |
| --- | --- |
| TDS keybinds | Reset |
| Recording hotkeys | Reset |
| Macro and advanced settings | Reset |
| Strategies | Not touched |
| Party settings | Not touched |
| Discord settings | Not touched |
| VIP server link | Not touched |

## Use the reset safely

1. Back up %APPDATA%\Ultimate_Macro\Options\Settings.tds.
2. Open Settings and choose Reset to Default.
3. Read the confirmation dialog before accepting.
4. Check keybinds and delays after the reset; run a supervised test match.
