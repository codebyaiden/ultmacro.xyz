# Where profile backups are saved

> Identify the local profile directory before importing or resetting settings.

Status: published
Version: v1.3.5
Category: Sessions & tools
Article: https://ultmacro.xyz/wiki/?article=where-profiles-are-saved

## Storage location

The v1.3.5 source creates %APPDATA%\Ultimate_Macro\Profiles when missing.

| Setting | Value |
| --- | --- |
| Profile directory | %APPDATA%\Ultimate_Macro\Profiles |

## Back up before importing

1. Open the directory through Win + R.
2. Make a copy of the profile you plan to import.
3. Use Profile Manager’s import preview before accepting replacements.
4. Test a short strategy after restoring a profile.
