## Windows settings

| Setting | Value |
| --- | --- |
| Resolution | 16:9, 1280×720 to 3840×2160 |
| Recommended resolution | 1920×1080 |
| Display scaling | 100% recommended |
| Taskbar | Visible; do not auto-hide |
| OCR language | English (United States) installed |

## Check before running

1. Open Windows Settings → System → Display and confirm resolution and scale.
2. Make the taskbar visible in Windows taskbar settings.
3. Ensure the English (US) OCR language pack is available.
4. Do not move or resize Roblox while a run is in progress.

## When clicks miss

If the macro clicks the wrong location, check display geometry before increasing delays. The macro uses screen coordinates and image matching.
