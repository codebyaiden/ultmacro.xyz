# Clicks miss or towers won't place

> Check display geometry before changing timing.

Status: published
Version: v1.3.x
Category: Troubleshooting
Article: https://ultmacro.xyz/wiki/?article=wrong-clicks
Source: /guide/troubleshooting/

## Fix screen-related misses

1. Check Windows resolution is supported 16:9 and scaling is preferably 100%.
2. Keep the Windows taskbar visible.
3. Set TDS UI Scale to Large and turn Screen Shake off.
4. Focus Roblox. Avoid resizing or moving its window once the run starts.
5. Test a bundled strategy for one match.

## If actions are late rather than misplaced

Try a higher Mouse Delay or Key Delay in Settings. A timing issue is different from a consistent wrong click position.
