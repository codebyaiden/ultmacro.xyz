# Keep release folders together

> Why Main.ahk must stay beside its libraries and resources.

Status: published
Version: v1.3.x
Category: Start here
Article: https://ultmacro.xyz/wiki/?article=zip-folders
Source: /guide/install/

## Required layout

Extract the release as a complete folder. Main.ahk relies on companion files and folders such as lib, Resources and submacros.

1. Extract all ZIP contents, not only Main.ahk.
2. Keep the original directory structure.
3. Launch Main.ahk from inside that extracted folder.

## When files go missing

Download the official release again, extract it into a clean folder, and compare folder contents before transferring personal strategies.
