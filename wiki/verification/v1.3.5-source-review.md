# Source verification: public release v1.3.5

Source: [Main.ahk at tag v1.3.5](https://github.com/UltimateMacro/Ultimate-Macro-New-Era/blob/v1.3.5/Main.ahk)
Release: [v1.3.5](https://github.com/UltimateMacro/Ultimate-Macro-New-Era/releases/tag/v1.3.5)

This review checked the **tagged public source code** of the latest GitHub release. The packaged \`TDS_Macro.zip\` could **not** be downloaded into the execution container due to restricted outbound networking, so ZIP-only files, installation behavior, assets, and the Windows UI **were not verified by running the package**. Do not describe these checks as Windows end-to-end tests.

## Confirmed source facts

| Area | Observed v1.3.5 source behavior |
|---|---|
| AutoHotkey version | \`#Requires AutoHotkey v2.0\`; startup checks require 64-bit |
| Options directory | \`%APPDATA%\\Ultimate_Macro\\Options\` |
| Main settings | \`%APPDATA%\\Ultimate_Macro\\Options\\Settings.tds\` |
| Bot settings | \`%APPDATA%\\Ultimate_Macro\\Options\\Discord-Bot-Settings.ini\` |
| Recorded strategies | \`%APPDATA%\\Ultimate_Macro\\Recordings\` |
| Profiles | \`%APPDATA%\\Ultimate_Macro\\Profiles\` |
| Bundled strategies | \`<macro folder>\\Resources\\Strats\` |
| Default TDS keys | Call of Arms C, Drop the Beat B, Support Caravan J, SWAT Van N, Raise the Dead V, Hologram K, Reposition L, Cancel placement Q, Upgrade E, Bottom path Z |
| Recorder defaults | Place F, Upgrade Ctrl+U, Align Ctrl+T, DJ Ctrl+D, Sell Ctrl+X, Delete last Ctrl+B, Inputs Ctrl+Shift+E, Hologram Ctrl+Alt+H |
| Hotkey upgrade mode | Presses game upgrade hotkey rather than clicking panel; release tooltip recommends ON |
| Upgrade Delay | Milliseconds between upgrade presses on one tower; Reset to Default sets 200 ms |
| Legacy Mode | Tooltip says 1920×1080 only; disables Auto Equip and tower targeting; changing it restarts the macro |
| Timescale | Tooltip calls 1.5× more stable; 2× requires matching strategies; zero tickets causes normal-speed continuation |
| Restart / Play Again | Restart after loss, Play Again after win |
| Reset to Default | Resets TDS/recording hotkeys and macro/advanced settings; does not touch strategies, party, Discord or VIP link |
| Export Logs | Settings contains button wired to \`ExportLogsForDevelopers\` |
| Settings saving | \`WireSettingsAutoSave()\` is called in the settings initialization |

## Editorial rules

- Only call a behavior **confirmed** when it is present in a tagged release source or reproduced with the released package.
- For a question about an untested **v1.4** feature, do not reuse v1.3.5 settings as a promised workflow.
- Research-topic pages may display **relevant instructions from existing published guides** but must never claim that this proves the title describes an existing bug or standalone solved issue.
- A screenshot belongs only to the exact UI/version it depicts. Do not generate fictional application screenshots or GIFs.
- Before adding ZIP-specific steps, compare this source review to a locally extracted official release ZIP and capture the Windows UI at the same release version.
